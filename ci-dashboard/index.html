Connect to GitHub

The dashboard calls the GitHub API straight from this browser. It needs a fine-grained personal access token limited to the repositories below, with these read-only repository permissions:

  • Actions: Read - workflow runs, jobs, queue
  • Administration: Read - self-hosted runners (idle / busy / offline)
  • Contents: Read - commits not yet deployed
  • Metadata: Read (selected automatically)
